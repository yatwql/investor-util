## 1. 业绩归因（Brinson 分解）

### 概述

目前报告只能回答"你赚了/亏了多少钱"，不能回答"为什么"——赚的钱是市场涨了（Beta）？还是选对了行业（配置效应）？还是选对了股票（选股效应）？Brinson 归因将超额收益分解为三个分量。

### 收益

- **回答核心问题**：跑赢大盘了吗？超额收益从哪来的？
- **指导调仓决策**：如果配置效应持续为正但选股效应为负，说明行业选对但标的选错了
- **形成完整叙事**：报告中"业绩归因"页签是对"量化指标"页签的最佳补充解释
- **数据已有**：组合持仓权重 + 各品种收益 + 基准指数收益，都是现有数据源

### 风险

- Brinson 模型假设持仓在归因期内固定不变，调仓频繁会引入误差
- 多期归因的连锁效应（Carino / Menchero 平滑算法）实现复杂度递增
- 基准选择对结果极度敏感：沪深 300 归因 vs 全市场归因结论不同

### 工作量估算

| 阶段 | 内容 | 天数 |
|------|------|------|
| 基础模型 | 单期 Brinson（配置+选股+交互） | 1 |
| 多期平滑 | Carino 或 Menchero 算法 | 1 |
| 报告输出 | Excel 页签 + HTML 图表 | 1 |
| 基准选择 | 用户可配置基准指数 + 自动匹配 | 1 |
| **合计** | | **4 天** |

### 实现路径

```
组合超额收益 R_p - R_b
  = 配置效应 Σ(w_pi - w_bi) × (R_bi - R_b)   [行业配重不同带来的收益差]
  + 选股效应 Σ(w_bi × (R_pi - R_bi))         [同行业内选股能力]
  + 交互效应 Σ(w_pi - w_bi) × (R_pi - R_bi)   [交叉效应，通常归入选股]
```

## 2. 调仓 What-if 模拟

### 概述

用户调仓前想看到"改了之后报告什么样"。通过双目录镜像机制：修改持仓前拍快照，改后跑对比报告，展示 diff 视图。

### 收益

- **决策支持**：不是跑完报告才发现"哎呀，调仓后夏普反而变差了"
- **可视化 diff**：旧持仓 vs 新持仓的量化指标对比、行业分布对比、相关性变化
- **工作流闭环**：分析 -> 假设 -> 验证 -> 行动
- **技术基础**：已有 `history_snapshot` 快照机制，再扩展一步即可

### 风险

- 需要加载两份持仓数据同时计算，内存和缓存使用量翻倍
- What-if 的净值曲线没有历史数据（新持仓还没跑过市场），只能做截面比较
- 用户可能误用：What-if 的量化指标不能回测（没有真实交易数据）

### 工作量估算

| 阶段 | 内容 | 天数 |
|------|------|------|
| 镜像机制 | double-entry 目录 + 持仓快照 | 1 |
| 对比管线 | 编排层同时加载两份+对比计算 | 2 |
| 报告输出 | diff 视图（Excel 增删改标注 + HTML 对比表） | 2 |
| **合计** | | **5 天** |

### 实现思路

```
data/holdings/
├── current/              # 当前持仓（实时运行默认加载）
└── snapshot_20260720/    # 快照：调仓前的状态

对比报告输出：
- Excel：新增/删除/权重变化 用颜色标注
- HTML：双栏对比布局 + 指标变化箭头（↑ ↓ →）
```

## 3. 多快照趋势追踪

### 概述

`history_snapshot` 已经存了多期 JSON 快照，但报告只展示当期。新增"组合演进"页签，展示多期快照合并后的趋势。

### 收益

- **看到变化**：行业配置在 3 个月内的变动趋势、穿透 TOP10 的集中度变化
- **回答"我怎么到这里的"**：回看历史配置可以复盘自己的决策轨迹
- **自动增量**：每次跑报告自动产生一份快照，趋势数据随时间自然积累
- **低增量成本**：快照数据已有，只需聚合 + 展示

### 风险

- 快照格式在版本升级中可能变更，需做向后兼容
- 首次使用时快照不足（< 3 期），图表数据点太少

### 工作量估算：**3 天**

### 主要输出

- **总市值趋势线**（时间序列 + 分账户堆叠）
- **行业配置流**（百分百堆叠面积图，行业占比随时间变化）
- **穿透 TOP10 变迁**（类似 Bar Chart Race）
- **集中度指数 HHI 趋势**
- **量化指标趋势**（夏普、波动率的历史变化）

## 4. 因子暴露分析

### 概述

组合在价值/成长/质量/动量/低波上的暴露度。通过因子代理指数（如 300 价值 = 大盘价值因子）估算组合风格偏移。

### 收益

- **理解赚什么钱**：组合风格是偏向价值还是成长？当前因子暴露是否与预期一致？
- **避免风格漂移**：买到"成长型基金"但实际持仓是价值风格，因子暴露暴露这种不一致
- **高级感**：这是专业机构的分析框架，在个人工具中提供有差异化

### 风险

- A 股的因子代理指数有限（只有规模/价值/成长少数几个），多因子模型数据不足
- 因子暴露计算需要回归分析（60 期以上数据），新人理解门槛高
- 基金持仓数据季度更新，因子暴露滞后 1-3 个月

### 工作量估算

| 阶段 | 内容 | 天数 |
|------|------|------|
| 因子代理 | 中证系列风格指数数据接入 | 1 |
| 回归模型 | OLS 回归暴露 + t 值显著性 | 1.5 |
| 报告输出 | 因子暴露柱状图 + 风格归属矩阵 | 1 |
| **合计** | | **3.5 天** |

### 实现思路

```
R_p = β₁R_value + β₂R_growth + β₃R_momentum + β₄R_quality + β₅R_lowvol + α + ε

不追求高精度（截面回归 > 时间序列回归），用 ≥36 期数据估算。
结果输出为"风格归属饼图"（价值 40% / 成长 30% / 动量 20% / 质量 10%）。
```
