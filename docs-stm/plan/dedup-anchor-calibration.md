# 新闻去重锚点校准复核（2026-09-18）

> 背景：用户运行 `.venv/bin/python scripts/calibrate-dedup-threshold.py` 后贴回输出，
> 其中「校准建议」给出三条动作（剥离年份、审查 bg≥2 跳过样本、审查同源 bg=2）。
> 复核结论：**建议不可照做**——两条已实现或已过时，且报告数字混了规则时代。
> 本文件记录复核证据、修正后的数字与处置决定，供后续校准复用。

## 1. 为什么原报告的数字不可信

锚点文件 append-only 且**无规则版本字段**，2026-08-17 收紧阈值前的旧样本与新样本混在一起：

| 证据 | 数字 |
|:--|:--|
| `cross_skip` 中 `ratio < 0.35`（当前候选区入口就是 0.35，今天不可能产生） | 5,000 / 10,779 |
| `cross_safe` 中标 `merged` 但 `bigram_overlap = 0`（今天直合要求 bg≥1） | 508（按当前掩码表重算仍 157） |
| `cross_merge` 中按当前 `_normalize_title`/`_STOP_BIGRAMS` 重算 bg **更低**的 | 1,593 / 3,431 |
| `cross_merge` ratio 下限 | 0.300（与 0.35 入口矛盾） |

旧 0.50 直合规则留下的误合并样例（如「行云科技签算力合同」vs「亿田智能签算力合同」）
仍在文件里，被报告当作「已合并样本」统计。

  真专名（bg=2 唯一可合并路径）的只有 **57 条**，其余 460 条共享项已模板词掩码或仅共享数字。

## 3. 原建议逐条核对

| 原建议 | 核对结论 |
|:--|:--|
| `bg≤1 但 ratio≥0.40：1761 条 → 让 `_normalize_title` 剥离年份` | **已实现**：`_normalize_title` 早有 `\b(?:19\|20)\d{2}\b` 与 `(?<=[a-zA-Z])\s*\d{4}\b`，ratio 侧另有 `_RATIO_CLEAN` 的 `\d{4}年\|\d+月\|\d+日`。其举例（「菲律宾股指下跌1%」vs「泰国基准股票指数下跌1.8%」）与年份无关，是板块指数骨架——跳过正确，不该改 |
| `bg≥2 且 ratio≥0.35 被跳过：452 条需审查` | 重算后仅 517 条仍 bg≥2、57 条有真专名；降阈值抽样多为误合并 → **不降阈值** |
| `同源 bg=2：27556 条建议审查` | 样例即「美国/美联储」类跨事件共享，阈值 4 正确；且同一标题对会因运行时源序不同重复登记（33 对），「有效同源样本 35564」偏虚 |

## 4. 处置

1. **校准工具口径对齐**（`scripts/calibrate-dedup-threshold.py` 重建）：阈值取自 `news_dedup`
   常量；用当前代码对标题重算 ratio/bg 并按当前阈值重判；记录时指纹不同的样本单列历史时代；
   删除已实现的年份建议与死代码；`--compact` 压缩锚点。
2. **锚点规则版本 + 体积治理**：`anchor_rules_version` 由 `_rules_fingerprint()` 自动派生
   （阈值 + 模板词表 + 方向词对 + 正则 + 行为探针），规则一改指纹即变，不再混代；
   加载超 32 MB 告警，`--compact` 实测 **152 MB → 17 MB（2.5 s，幂等）**。
3. **规则微调**：`_TOKEN_LIKE` 要求英数 token 含字母（纯数字不再算专名证据，翻转 24 对
   误合并）；补 5 组价格方向对（站稳/跌破、走高/走低、上探/下探、回升/回落、走软/走强，
   当前锚点集内无决定性命中，属预防性补充）。
4. **已评估未采纳**：把方向对立防护扩到安全区（ratio ≥ 0.50）。实测命中方向词的 6 对样本
   **4 对是真重复**（同标题内同时出现两个方向词、或对立方词属另一主体），扩展会误拦真重复。
