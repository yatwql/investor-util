# 菜单操作手册

> **CLI 命令行模式**：CLI 模式（`python -m src.python.cli`）使用 `--help` 参数查看等价操作，无需 TUI 界面。
> 详见[定时任务配置指南](how-to-schedule.md)。

## 主菜单总览

启动程序后进入 TUI 文本界面主菜单：

```
  > [E] 生成基础版Excel分析报告
    [B] 生成标准报告(Excel+HTML) [按章节配置]
    [L] 生成完整报告(Excel+HTML) [含LLM，按章节配置]
    [C] 配置持仓信息目录
    [F] 配置持仓信息文件名
    [O] 配置报告输出目录
    [1] 更新基础类缓存
    [2] 更新行情类缓存（含价格/指数等）
    [3] 清理过期缓存文件
    [4] 查看缓存/状态统计
    [P] 配置报告可选章节（基金分析/市场新闻/历史走势）
    [I] 管理对比指数池
    [A] 配置持仓匿名化（代码/名称脱敏）
    [S] 配置LLM分析章节
    [R] 刷新配置
    [X] 退出
```

### 键盘操作

| 操作 | 说明 |
|------|------|
| **↑ ↓** | 方向键上下移动选择项 |
| **Enter** | 确认执行当前选中项 |
| **字母/数字键** | 快捷键直达功能 |
| **Ctrl+C** | 退出程序 |

> 方向键在 SSH / tmux 下可能无效，可使用字母/数字快捷键替代。

## 各菜单项详解

### 报告生成类

#### [E] 生成基础版 Excel 分析报告

读取持仓 → 获取行情 → 生成 Excel 报告，包含 6 个核心页签：
- 投资分析汇总、市值核算明细表、持仓分类表、资产穿透 TOP10、基金业绩分析、数据源可用性矩阵

无新闻、无 LLM、无基金深度分析。生成速度最快，适合快速查看持仓概况。

#### [B] 生成标准报告（Excel+HTML）[按章节配置]

在 E 的基础上增加：
- **财经新闻** — 5 源并行获取，与持仓关键词关联匹配
- **组合历史走势 + 回撤分析** — 视 `history.analysis` 配置而定
- **基金深度分析** — 基金经理变更监控、持仓重合度矩阵、持仓集中度监控、基金风格分析
- **环比摘要/快照对比** — 与上次报告自动对比

不含 LLM 分析。

#### [L] 生成完整报告（Excel+HTML）

全功能报告，在 B 的基础上增加：
- **LLM 多模块分析** — 全球政经局势、智囊团深度复盘、持仓体检报告、穿透深度分析、新闻关联分析（可选）
- **行业资金流向** — 注入实时行业资金流数据
- **LLM API 用量页签** — Token 消耗统计、费用估算

> **建议使用顺序**：按菜单 L 生成全量报告（含 LLM），如需单独生成不含 LLM 的版本可随后执行 B 或 E，程序会复用已缓存的行情和新闻数据。

### 配置管理类

#### [C] 配置持仓信息目录

修改持仓 `.xlsx` 文件所在目录路径。程序会列出该目录下所有 `.xlsx` 文件供选择。

#### [F] 配置持仓信息文件名

修改要读取的持仓文件名。配合 [C] 使用。

#### [O] 配置报告输出目录

修改报告输出目录（默认 `reports/`）。每次生成同时保留两份：
- **最新版** — `个人投资分析报告.xlsx` / `个人投资分析报告.html`（覆盖写入）
- **归档版** — `个人投资分析报告-YYYYMMDD-HHMMSS.xlsx` / `.html`（按日期命名）

> 程序自动清理 180 天前的归档目录，如需长期保留请移出 `reports/`。

#### [P] 配置报告可选章节

交互式配置报告可选章节的显示/隐藏：
- **基金深度分析** — 基金经理变更监控/持仓重合度矩阵/持仓集中度监控/基金风格分析
- **市场新闻** — 财经新闻热点与持仓关联分析
- **历史走势** — 组合历史走势/回撤分析

关闭的章节在报告中完全隐藏，剩余章节自动连续重新编号。LLM 分析章节可见性通过菜单 [S] 或 `llm_settings.json` 控制。

#### [S] 配置 LLM 分析章节

交互式子菜单，分两组控制：

**标准 LLM 模块（1-5）**：5 个 LLM 分析模块独立启停，实时保存到 `llm_settings.json` 的 `enabled_llm`。禁用模块在报告中完全跳过，不调用 LLM API。

**⚗ 实验性辩论模式（6-8）**：3 项智囊团复盘增强通路，面板中以 ⚗ 标识区分，默认全部关闭：
| 编号 | 名称 | 效果 |
|:----:|:-----|:------|
| 6 | ⚗ 辩论-正反辩论 | 智囊团复盘→三段式(白脸→黑脸→综合)，pro(绿)/con(红)/synthesis(金)三色块 |
| 7 | ⚗ 辩论-条件推理 | 注入预设市场情景(上涨/下跌/震荡)，使分析结果情景化 |
| 8 | ⚗ 辩论-集中度问答 | 单品种占比≥20%时自动生成集中度量化评估块 |

> **⚗ 辩论模式说明**：6/7/8 是三项**相互独立的开关**，默认全部关闭，可任意组合开启。**正反辩论（6）**开启后，智囊团复盘改为"看多 → 看空 → 收敛结论"三段式输出；**条件推理（7）**为分析注入上涨/下跌/震荡情景，使结果情景化；**集中度问答（8）**在单品种占比≥20% 时自动附加集中度量化评估。

辩论模式开启后，智囊团复盘页签标题尾部附加 `(实验)` 标签。同一次报告周期内辩论模式与标准模式互斥（辩论优先）。

多个辩论模式可同时开启（如正反辩论+条件推理）。启用后，**HTML 报告页脚**和 **LLM 用量页**会显示当前启用的模式组合标识（如"🧪 辩论模式 · 正反辩论+条件推理"），方便确认生效的组合。**Excel 报告**的 LLM 用量行也会展示相同的组合标识。

> **⚠ 实验阶段说明**：辩论模式当前为实验性功能，输出质量可能不稳定。TUI 面板中辩论开关区域以 ⚗ 标识和独立分隔线区分，底部附实验阶段提示。开启后如生成失败会自动回退标准模式，不影响报告生成。

> **关于 Feature Flag**：辩论模式开关存储在 `data/config/features.json`（不必须存在，首次切换自动创建）。该文件为纯 JSON 格式（不支持 `//` 注释），仅记录与代码默认值不同的开关。手动编辑示例：
>
> ```json
> {
>   "llm_debate_procon": true,
>   "llm_debate_conditional": true
> }
> ```
>
> 可用的辩论开关对照：
>
> | features.json 键名 | 菜单编号 | 功能 |
> |:-------------------|:--------:|:------|
> | `llm_debate_procon` | 6 | 辩论-正反辩论 |
> | `llm_debate_conditional` | 7 | 辩论-条件推理 |
> | `llm_debate_qa_concentration` | 8 | 辩论-集中度问答 |
>
> 除辩论开关外，`features.json` 还统一管理匿名化模式（`anonymization.mode`）、新闻分类（`news_cls`）、历史走势（`history_portfolio`/`history_benchmark`）、量化指标（`metrics_*`）、缓存清理（`cache_daily_cleanup`）、交互图表（`enable_interactive_charts`）等共 29 项开关。完整清单见[配置指引-功能开关 §M](how-to-config.md#m-功能开关featuresjson)。

#### [A] 配置持仓匿名化（代码/名称脱敏）

交互式设置持仓匿名化模式。支持 4 种模式：
- **关闭** — 显示真实名称和代码（默认）
- **代码显示** — 名称替换为"品种A/B/C…"，保留证券代码和盈亏数据
- **完全匿名** — 名称→"品种X"，代码→"000XXX"，盈亏→±XX%
- **汇总模式** — 仅显示大类汇总，不展示单品种明细

选择后立即保存到 `config.json` 的 `anonymization.mode`。匿名化仅在报告生成阶段生效，不修改原始持仓文件。

#### [R] 刷新配置

重新加载 `config.json`、`llm_settings.json`、`llm_key.json`，立即生效无需重启程序。

#### [I] 管理对比指数池

交互式维护竞争语境对比指数池。可添加/删除指数代码，用于报告中组合与基准的多维度对比（收益、夏普、波动率、最大回撤）。默认预设池为沪深300 + 中证500 + 中证全债，无需手动维护即可获得有意义的对比。

### 缓存管理类

#### [1] 更新基础类缓存

清除并重新获取：基金业绩、持仓明细、基准、行业分类、新闻、盈利预测、行业资金流向、分红/基金经理/持仓重合度/基金风格扩展数据。

**附带清除**：财经新闻热点与持仓关联分析（LLM 缓存）。

纯股票组合时自动跳过基金相关刷新，但仍主动重拉行业分类、分红、盈利预测、资金流向。

#### [2] 更新行情类缓存（含价格/指数等）

清除并重新获取：价格行情、指数行情。

**附带清除** LLM 缓存：智囊团深度复盘、全球政经局势、持仓体检报告、穿透深度分析。

适合：切换到另一份持仓文件时，一键清理依赖旧持仓的缓存。

#### [3] 清理过期缓存文件

按 TTL 扫描删除已过期的缓存文件。不影响未过期的缓存。

#### [4] 查看缓存/状态统计

仅浏览，不执行删除操作。分三块展示：

**data/cache/**（API 响应缓存）：
- 文件总数 / 总大小
- 命中率统计
- 按前缀分类统计
- 最大文件 TOP3
- 过期文件数预览（可通过菜单 [3] 清理）

**data/history/snapshots/**（持仓快照）：
- 快照文件数 / 总大小
- 最新快照时间
- 超期自动删除，不随缓存清理

**data/state/**（运行时状态文件）：
- 状态文件数 / 总大小
- 跨会话持久化，不随缓存清理

## F1 快照自动清理

B/L 菜单生成报告时自动保存持仓快照（环比对比用），并清理超过 60 天的旧快照（保留天数可通过 `config.json` 的 `history.snapshot_retention_days` 配置），避免 `data/history/snapshots/` 目录无限堆积。

## 生成报告建议顺序

1. **首次使用** — 确保持仓文件就绪后，直接按菜单 **L**（全量报告，含 LLM）
2. **日常更新** — 菜单 **`[1]`** 更新基础缓存 → 菜单 **B** 生成含新闻的报告
3. **需最新行情** — 菜单 **`[2]`** 更新持仓缓存 → 菜单 **L** 生成完整报告
4. **仅看概览** — 菜单 **E** 快速生成基础 Excel 报告
