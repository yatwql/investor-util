# Web 浏览器模式使用指南

Web 浏览器模式是本系统的第三种交互入口：在浏览器内完成「**上传持仓 Excel → 选择报告格式 → 实时查看生成进度 → 预览 HTML / 下载 Excel**」全流程，无需终端交互。本文从用户角度完整介绍 Web 模式的使用方法；启动与参数细节见[快速开始](how-to-start.md)「方式四」。

> **适用人群**：不熟悉终端的用户、希望可视化操作的用户、需要在局域网内共享使用的场景。
> **数据隔离**：Web 模式与 TUI / CLI 共用同一套管线、缓存与配置文件，可交替使用；同一时刻请保持单一入口运行（共用输出目录，并行会互相覆盖最新产物）。

---

## 1. 启动与访问

```bash
# Windows PowerShell
.\scripts\launch.ps1 web

# Linux
./scripts/launch.sh web

# 手动启动（环境已就绪时）
.venv/bin/python -m src.python.web
```

启动成功后浏览器访问 **http://127.0.0.1:8000** 即可打开首页。默认仅监听本机回环地址；如需局域网内其他设备访问，加 `--host 0.0.0.0` 参数（⚠️ 无内建认证，请仅限可信网络，见 [§7 安全注意](#7-安全注意)）。

---

## 2. 首页布局总览

首页自上而下分 **7 个卡片区**，按使用顺序排列：

| 区 | 名称 | 用途 |
|:--:|:-----|:-----|
| ① | 上传持仓 | 选择持仓 Excel 文件 |
| ② | 生成报告 | 选择报告格式、生成选项与生成用途，提交任务 |
| ③ | 配置编辑 | 修改系统配置（与 TUI 主菜单一致，7 组，即改即存） |
| ④ | 生成进度 | 提交后实时展示当前阶段与事件流 |
| ⑤ | 生成结果 | 完成后展示预览 / 下载入口与错误提示 |
| ⑥ | 运行状态 | 系统信息、数据源健康检测、历史运行记录 |
| ⑦ | 日志查看 | 手动加载并筛选查看最近运行日志 |

## 3. 生成一份报告（完整流程）

### 3.1 第一步：上传持仓

点击 ① 区「选择文件」，选择持仓 Excel（仅支持 `.xlsx`，单文件 ≤10MB）。上传即校验：

- **格式校验**：文件必须是合法的 Excel（伪装扩展名 / 损坏文件会拒绝并提示）。
- **内容预检**：行数上限 5000；空持仓或无有效账户会立即提示，避免「上传成功、生成失败」。
- 校验通过后页面显示文件已就绪（含账户数量），方可继续。

### 3.2 第二步：选择报告格式与生成选项

在 ② 区选择：

- **报告格式**：
  - `仅 Excel`（basic）—— 约 1 分钟
  - `HTML + Excel`（both）—— 约 2 分钟
  - `全量含 LLM`（full）—— 约 5 分钟（追加 LLM 智囊团分析章节）
- **获取历史走势数据**：勾选后拉取历史净值 / 回撤数据（默认跟随配置 `history.fetch_mode`，仅 both/full 有效）。
- **强制重新生成 LLM 内容**：跳过 LLM 缓存强制重写（仅 full 生效，通常不必勾选）。

### 3.3 第三步：选择生成用途

提交前选择本次任务的「生成用途」，决定是否写入正式持仓与共享快照时间线：

| 生成用途 | 说明 | 快照 |
|:--------|:-----|:-----|
| **临时试算**（默认，推荐） | 仅本次生成使用，不更新正式持仓，安全尝试 | 写入隔离的试算域，与正式历史互不污染 |
| **正式更新** | 覆盖 `data/holdings/` 正式持仓并写入共享快照时间线 | 与 TUI / CLI 正式历史共用 |

选择「正式更新」后，还需选择**输入来源**：

- **上传新文件覆盖**：旧正式文件先备份为 `.bak`，再用已上传的新文件生成。
- **直接用当前正式持仓文件**：无需上传，直接读取现有正式文件生成（适合正式文件已是最新时）。

> ⚠️ 正式更新会修改正式持仓文件，勾选「我已知晓」确认后才能提交。普通尝试请用默认的「临时试算」。

### 3.4 第四步：提交生成并查看进度

点击「生成报告」提交。④ 区实时展示：

- **进度条**：当前完成百分比（按报告阶段推进）。
- **事件流**：逐条展示当前阶段消息（如「正在获取行情数据…」「正在生成 Excel…」「报告生成完成」）。

> 同一时间仅执行一个生成任务，新任务进入排队（队列最多 3 个，含运行中）。提交后页面会轮询展示最新状态。

### 3.5 第五步：预览与下载结果

生成完成后 ⑤ 区展示结果入口：

- **预览**：浏览器内打开 HTML 报告（both/full 有此项）。
- **下载**：下载 Excel / HTML 产物。

失败时 ⑤ 区展示错误提示与处理建议：部分失败（黄色告警）或严重错误（红色提示查看日志）时，无效产物按钮隐藏，可重新上传再生成。

## 4. 配置编辑面板

③ 区「配置编辑」面板与 TUI 主菜单可编辑项**完全一致**（完整镜像），共 **7 组**：

| 组 | 配置项 | 对应 TUI 菜单 |
|:--|:--|:--|
| 路径与文件 | 持仓目录 / 持仓文件名 / 输出目录 | `[C]` / `[F]` / `[O]` |
| 报告章节 | 基金深度分析 / 市场新闻 / 组合历史走势+回撤 / 组合演进 / 行动建议 | `[P]` 1~5 |
| 报告增强子模块 | 数据质量仪表盘 / 行业Beta子表 / 候选基金比较子表 / 成本流水 / 估值分位 / 市场温度 | `[P]` 6 |
| 持仓匿名化 | off / code_display / full_anonymous / summary | `[A]` |
| 对比指数池 | 添加 / 删除 / 重置默认（沪深300、中证500、中证全债） | `[I]` |
| LLM 分析章节 | 全球宏观 / 专家评审 / 健康检查 / 穿透深挖 / 新闻关联 | `[S]` |
| 辩论实验功能 | 正反辩论 / 条件推理 / 集中度问答（⚗ 实验性，默认关闭） | `[S]` 6~8 |

### 4.1 保存语义：即改即存

面板保存语义与 TUI 一致——**改动即保存**，无「保存」总按钮：

- **开关类**（报告章节 / 子模块 / LLM 分析章节 / 辩论实验）：勾选 / 取消勾选**立即生效**。
- **单选类**（匿名化模式）：切换**立即生效**。
- **文本类**（路径与文件）：输入后点该项旁的「保存」按钮提交。
- **对比指数池**：通过「添加」「删除」「重置」动作提交。

每次提交后控件短暂禁用并回读服务端最新值；失败则恢复改动前值并显示错误原因。

### 4.2 写盘与备份

- 配置修改**立即写入**共享配置文件（`config.json` / `llm_settings.json` / `features.json`），TUI / CLI 下次读取即生效（缓存按文件修改时间自动失效，无需手动刷新）。
- 写配置文件**前自动备份**为 `{文件}.bak`（单槽轮转，仅保留最近一份）。如需还原：找到对应 `.bak` 文件，改回原文件名即可。

### 4.3 使用提示

- Web 与 TUI / CLI 编辑的是**同一份配置**。请避免 Web 与 TUI 同时修改配置（跨进程并发读-改-写可能互相覆盖）；`.bak` 提供最近一份回滚。
- LLM 辩论三模块（`debate_pro` / `debate_con` / `debate_synthesis`）为内部注册项，TUI 与 Web 面板均不展示，辩论输出由下方三个实验开关控制。
- 全部配置项的详细说明见[常规配置指引](how-to-config.md)「P. Web 模式配置编辑」及对应章节。

## 5. 运行状态区

⑥ 区包含三个卡片：

- **系统信息**：程序版本、本机 IP、持仓目录 / 文件、输出目录、新闻抓取上限、持仓文件就绪状态、持仓匿名化模式、隐私声明状态、LLM 配置状态（provider / 模型 / 策略 / 熔断 / 模块偏好）。
- **数据源健康**：各行情数据源可达性检测结果（60s 缓存），可点「重新检测」强制刷新。健康检测不消耗行情额度，可随时使用。**代理诊断提示**：当全部数据源同时失败且多数为「连接被拒」（WinError 10061 / Errno 111）时，卡片顶部追加整卡警示条，提示检查本机系统代理或 `HTTP(S)_PROXY` 环境变量（HTTP 客户端默认读取系统代理，代理软件未运行会令所有请求被路由到死代理）。
- **历史运行记录**：最近 10 条报告生成任务（类型 / 耗时 / 退出码），短缓存刷新。

---

## 6. 日志查看区

⑦ 区为「日志查看」卡：**手动加载**（点「加载日志」按钮），不自动轮询——日志读取为高 IO 操作，自动刷新会持续占用磁盘与请求通道，故按需加载。

- **级别筛选**：`<select>` 选择最小级别阈值（ALL / DEBUG / INFO / WARNING / ERROR / CRITICAL），再点「加载日志」生效。
- **折叠展示**：每条记录用原生 `<details>` 折叠，标题行显示 `time [LEVEL] message` 首行；多行正文（如 traceback）在展开后显示，`<pre>` 保留缩进。ERROR 红 / WARNING 黄配色，装饰性横幅置灰。
- 后端对应 `GET /api/logs`：非法级别返回 400、`lines` 限制在 [1,5000]、读取失败返回 500。

## 7. 与其他模式的关系

| 维度 | 说明 |
|:-----|:-----|
| 配置共享 | 三入口编辑同一份配置，改动互相可见 |
| 缓存共享 | 行情 / 持仓缓存全局共用，TUI 更新后 Web 立即可用 |
| 产物互斥 | 共用输出目录，同一时刻保持单一入口运行。启动时对 output_dir 原子抢占写锁（锁文件），检测到锁已被其他入口持有则记录警告、不阻塞启动（产物竞态交由用户决策）；端口被占用则报错提示换端口 |
| 快照时间线 | 临时试算写入隔离域；正式更新写入共享历史（TUI / CLI 可对比） |

---

## 8. 安全注意

- Web 模式**无内建认证**。默认仅监听 `127.0.0.1`（本机）；`--host 0.0.0.0` 后局域网内任何设备均可访问，请仅限可信网络使用。
- 公网部署**必须**前置反向代理做 basic auth（Web 自身不提供认证）。
- 配置编辑面板的写操作自带同源校验（非浏览器跨站请求会拒绝），但不替代访问控制。
