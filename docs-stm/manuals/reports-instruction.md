# 报告文件结构

## Excel 报告

| # | 页签 | 内容说明 |
|:--|------|----------|
| 1 | **1.投资分析汇总** | 当前时间、交易日、A 股/美股指数行情、总市值/成本/盈亏/本日盈亏、各账户小计、更新状态 |
| 2 | **2.市值核算明细表** | 15 列明细：账户、名称、代码、最新价、净值日期、昨日价、取价方式、溢价率、份额、市值、成本、盈亏、收益率、本日盈亏、取价渠道。取价方式蓝色标识（场内收盘价(T)→蓝、官方净值(T)→蓝、QDII 官方净值(T-1)→蓝），分账户小计+总计 |
| 3 | **3.持仓分类表** | 10 列：资产属性、投资分类、名称、代码、市值、成本、盈亏、收益率、本日盈亏、年均股息率。按资产属性和投资分类分组统计 |
| 4 | **4.资产穿透TOP10** | 10 列：排名、名称、代码、穿透市值、占比、板块、概念、预测EPS(2025E)、年均股息率、来源明细。基金拆解为底层标的合并排序，底部标注无法获取穿透数据的基金 |
| 5 | **5.基金业绩分析** | 12 列：基金、代码、类型、近3月/6月/12月收益率、累计盈亏(¥)、持仓收益率、业绩基准、业绩评价、同类排名、机构覆盖（研报家数+预测EPS）。业绩标色：优秀→红、稳定→蓝、偏差→绿 |
| 6 | **6.财经新闻热点与持仓关联分析**（菜单 B/L） | 5 源新闻与持仓关键词匹配结果，含标题、来源、时间、关联度。关联关键词按来源富化显示（持仓→蓝色、穿透→紫色、概念→橙色、行业→灰色），可选 LLM 二次关联分析 |
| 7 | **7.智能预警**（菜单 B/L） | 行业资金流向联动预警 + 新闻情绪聚合，自动附带，不依赖 LLM |
| 8 | **8.全球政经局势**（菜单 L） | LLM 基于指数行情和持仓结构生成的全球政经局势 |
| 9 | **9.智囊团深度复盘**（菜单 L） | LLM 三阶段圆桌会议：召集令→辩论→定音锤，含调仓建议和风险预警 |
| 10 | **10.持仓体检报告**（菜单 L） | LLM 从风险分散度、流动性、收益合理性、成本结构四维度量化评分并给出改进建议 |
| 11 | **11.穿透深度分析**（菜单 L） | LLM 从行业集中度、国别/币种暴露角度生成深度分析，含行业集中度仪表盘和外汇风险敞口 |

> **注意**：LLM API 用量（Token 消耗、费用估算）在菜单 L 时追加至「1.投资分析汇总」页签底部，非独立页签。但 HTML 报告第 12 节单独渲染该章节。

## HTML 报告

单页渲染以上全部 11 个功能页签 + LLM API 用量（共 12 个章节，含智能预警），响应式 CSS 自适应桌面/移动端。额外特性：
- 盈亏正数红色、负数绿色着色
- 取价方式蓝色标识（与 Excel 端规则一致）
- 新闻来源可点击跳转
- 基金业绩评价带颜色标签
- LLM API 用量章节展示各模块 Token 消耗、费用估算及 per-module 模型/用量明细
- 页脚标注生成时间和版本号
- LLM 内容为条件渲染（仅菜单 L 时显示）

# 基金业绩评价标准

基金业绩分析采用 **三层计算逻辑**，数据来源于天天基金 API：

## 第 1 层：基础评级

基于同类排名百分位（`Data_rateInSimilarPersent`）：

| 排名百分位 | 基础标签 |
|:-----------|:---------|
| ≤ 20%（前 1/5） | **优秀** |
| 20% ~ 30% | **良好** |
| 30% ~ 50% | **稳定** |
| > 50%（后 1/2） | **偏差** |

> API 无百分位数据时降级使用排名/总数折算百分位。

## 第 2 层：超额收益修正

基于 `Data_performanceEvaluation` 中的超额收益评分调整评级：

| 超额收益评分 | 修正规则 |
|:-------------|:---------|
| ≥ 80 | 基础评级**上调一级**（如 良好 → 优秀） |
| 40 ~ 80 | 维持基础评级不变 |
| < 40 | 基础评级**下调一级**（如 稳定 → 偏差） |

## 第 3 层：显示与标色

| 最终标签 | Excel / HTML 标色 | 显示文本 |
|:---------|:------------------|:---------|
| **优秀** | 红色 `#CC0000` | 持续跑赢基准，超额收益显著 |
| **良好** | 默认 | 稳定跑赢基准，组合管理得当 |
| **稳定** | 蓝色 `#0066CC` | 收益率稳健，波动控制良好 |
| **偏差** | 绿色 `#009900` | 近期表现欠佳，需关注持仓变化 |
