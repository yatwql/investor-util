## LLM API 用量页签/章节说明（页签 16 / HTML 第 16 节）

本页签/章节是对当前会话中所有 LLM 调用量的**统计汇总**，并非独立的 LLM 生成内容。跟踪范围包括全部 5 个 LLM 子模块（1 个可选）（全球政经局势、智囊团深度复盘、持仓体检报告、穿透深度分析 + 已启用 LLM 服务的财经新闻热点与持仓关联分析）。

### 触发条件

| 条件 | 行为 |
|:-----|:-----|
| 菜单 L 执行且至少有一个 LLM 模块触发 API 调用或缓存命中 | ✅ 正常生成页签/章节 |
| 菜单 L 执行但所有模块均为缓存命中（无实际 API 调用） | ✅ 生成，汇总区标注"无新增 API 调用" |
| 菜单 L 执行但全部 LLM 模块被禁用 | ❌ 整页不渲染（无用量数据） |
| LLM API Key 未配置 | ❌ 整页不渲染（无用量数据） |
| 菜单 B / H / E（不含 LLM） | ❌ 不生成 |

### 与 LLM 分析章节的关系

LLM API 用量页签/章节被动跟踪以下 5 个子模块（1 个可选）的调用数据，**不能单独启用或关闭**，随菜单 L 的 LLM 分析章节一并输出：

| 模块 | 触发条件 | 说明 |
|:-----|:---------|:-----|
| 全球政经局势 | 菜单 L | 始终启用 |
| 智囊团深度复盘 | 菜单 L | 始终启用 |
| 持仓体检报告 | 菜单 L | 始终启用 |
| 穿透深度分析 | 菜单 L | 始终启用 |
| 财经新闻热点与持仓关联分析（LLM 二次关联部分） | 菜单 L + `enabled_llm.news_correlation = true` | 可选模块，仅在 LLM 新闻关联开启时计入统计 |

> **注意**：财经新闻热点与持仓关联分析的基础新闻匹配（关键词富化）**不消耗 LLM Token**，仅在其 `enabled_llm.news_correlation = true` 时，LLM 二次关联分析产生的 Token 才计入本页签。

### Excel 格式

页签名：`16.LLM API 用量`，位于 Excel 报告最右侧。

**系统缓存统计：** 页签底部追加"▎数据缓存系统"区域，展示数据缓存命中/未命中/总请求数/命中率（仅在有缓存请求时显示）。

#### ① 汇总数据区（顶部，仅在有实际 API 调用时显示）

以键值对形式列出本会话的 LLM 整体用量：

| 字段 | 说明 | 示例 |
|------|------|------|
| API 调用次数 | 本次生成实际发起的 API 请求次数（缓存命中不计入） | `4 次` |
| 模型 | 使用的模型名称（多个模型 `/` 分隔） | `deepseek-v4-flash` |
| Endpoint | API 端点地址 | `https://api.anthropic.com/v1/messages` |
| 输入 Token | 所有请求的输入 Token 总和 | `12,345` |
| 输出 Token | 所有请求的输出 Token 总和 | `5,678` |
| 总 Token | 输入+输出合计 | `18,023` |
| 缓存命中 Token | 缓存命中的 Token 数（仅 >0 时显示） | `2,100` |
| 累计费用 | 按模型定价估算的总费用 | `¥0.0254` |

> 无实际 API 调用时（全部命中 LLM 缓存），该区域显示"无新增 API 调用，数据全部来自缓存"提示，不再显示空字段。

#### ② 模块明细表

每行对应 5 个 LLM 子模块（1 个可选）之一（新闻关联分析仅在启用时显示），共 10 列：

| 列 | 说明 | 示例值 |
|----|------|--------|
| 模块 | LLM 子模块中文名称 | `全球政经局势` |
| 状态 | 该模块的执行结果 | `成功` / `缓存` / `已禁用` / `LLM API 调用失败` |
| 模型 | 该模块实际使用的模型 | `deepseek-v4-flash` |
| 输入 Token | 该模块的输入 Token 数 | `3,200` |
| 输出 Token | 该模块的输出 Token 数 | `1,321` |
| 总 Token 用量 | 输入+输出合计 | `4,521` |
| 缓存命中 Token | 缓存命中的 Token 数（无缓存时 `—`） | `2,100` |
| 费用 | 该模块的估算费用（缓存命中时标注"已计入原调用"） | `¥0.0063` |
| LLM 缓存 | 是否命中 LLM 缓存 | `✓` / `—` |
| Thinking | 是否启用了 Extended Thinking | `✓` / `—` |

##### 状态颜色标识

| 状态 | 标色 | 含义 |
|:-----|:-----|:------|
| **成功** | 绿色 (#E8F5E9 填充) | API 调用成功，生成正常 |
| **缓存** | 蓝色 (#2e86c1 文字) | 结果来自缓存文件，未发起 API 请求 |
| **已禁用** | 灰色 (#F5F5F5 填充) | 该模块在菜单 S 或配置中已关闭，未执行 |
| **失败** | 红色 (#FFEBEE 填充) | 该模块执行出错，具体原因见下方 |

##### 失败状态说明

| 失败原因 | 说明 |
|:---------|:-----|
| LLM 未配置 | `llm_key.json` 或 `llm_settings.json` 未正确设置 API Key |
| API 调用失败 | LLM 服务端返回了错误（如 400/500） |
| 网络连接失败 | 客户端无法连接到 LLM 端点（如 DNS 解析失败、连接被拒） |
| 请求超时 | LLM API 响应时间超过设定的超时阈值 |
| 熔断冷却中 | 该端点因连续错误被熔断器临时禁止访问，等待恢复 |

### HTML 格式

自动渲染在报告第 16 节（穿透深度分析之后），格式与 Excel 一致，分汇总区和模块明细表两部分。底部追加系统数据缓存统计区域：

| 区块 | HTML 渲染方式 |
|:-----|:-------------|
| 汇总区 | `<h2>LLM API 用量</h2>` 标题下，以表格展示各汇总字段 |
| 模块明细表 | 状态带颜色标签（`<span style="color:#27ae60">成功</span>` 等），和汇总区在同一区域 |
| 无用量场景 | 整个区块不渲染（不在页面中留下空区域） |

### 汇总页补充信息

汇总页签（页签 1）不再追加 LLM 用量区块。LLM API 用量信息统一在独立页签 `16.LLM API 用量` 展示（仅菜单 L 时显示）。

## HTML 报告

单页渲染以上全部功能页签（B 系列启用时最多 16 个，含 LLM API 用量），CSS 样式桌面端优先。额外特性：
- 盈亏正数红色、负数绿色着色
- 取价方式蓝色标识（与 Excel 端规则一致）
- 新闻来源可点击跳转
- 基金业绩评价带颜色标签
- LLM API 用量在报告底部渲染，与 Excel 端格式一致（汇总区+模块明细表），状态带颜色标签（成功→绿、缓存→蓝、失败→红、禁用→灰），含新闻 LLM 关联分析（启用时）
- LLM 内容（含 LLM API 用量章节）为条件渲染，仅菜单 L 时显示
- 页脚标注生成时间和版本号

## 基金业绩评价标准

基金业绩分析采用 **三层计算逻辑**，数据来源于天天基金 API：

### 第 1 层：基础评级

基于同类排名百分位（`Data_rateInSimilarPersent`），**5 级**评级体系：

#### 1.1 默认阈值（主动型/混合型）

| 排名百分位 | 基础标签 |
|:-----------|:---------|
| ≤ 10%（前 1/10） | **优秀** |
| 10% ~ 30% | **良好** |
| 30% ~ 50% | **稳定** |
| 50% ~ 75% | **偏差** |
| > 75%（后 1/4） | **较差** |

#### 1.2 类型差异化阈值

不同基金类型使用差异化排名百分位阈值，更客观反映同类相对表现：

| 基金类型 | 优秀 | 良好 | 稳定 | 偏差 | 较差 |
|:---------|:----|:----|:----|:----|:----|
| 默认（主动/混合） | ≤ 10% | 10~30% | 30~50% | 50~75% | > 75% |
| 债券型 | ≤ 15% | 15~35% | 35~55% | 55~80% | > 80% |
| QDII | ≤ 15% | 15~35% | 35~55% | 55~80% | > 80% |
| 指数型 | ≤ 10% | 10~25% | 25~45% | 45~70% | > 70% |

> 债券型/QDII 使用更宽松阈值（债券型同类分化较小，QDII 样本量少），指数型使用更严格阈值（被动管理差异本应极小）。
> API 无百分位数据时降级使用排名/总数折算百分位。

### 第 2 层：超额收益修正

基于 `Data_performanceEvaluation` 中的超额收益评分调整评级：

| 超额收益评分 | 修正规则 |
|:-------------|:---------|
| ≥ 80 | 基础评级**上调一级**（如 良好 → 优秀） |
| 40 ~ 80 | 维持基础评级不变 |
| < 40 | 基础评级**下调一级**（如 偏差 → 较差） |

### 第 3 层：显示与标色

| 最终标签 | Excel / HTML 标色 | 显示文本 |
|:---------|:------------------|:---------|
| **优秀** | 红色 `#CC0000` | 持续跑赢基准，超额收益显著 |
| **良好** | 默认 | 稳定跑赢基准，组合管理得当 |
| **稳定** | 蓝色 `#0066CC` | 收益率稳健，波动控制良好 |
| **偏差** | 绿色 `#009900` | 近期表现欠佳，需关注持仓变化 |
| **较差** | 深绿 `#006400` | 同类排名靠后，建议评估持续持有理由 |
