## LLM API 用量页签说明（页签 12）

仅在执行 **菜单 L（LLM 全量生成）** 时创建，位于 Excel 报告最右侧。

### 出现条件

- **必须**：菜单 L 执行完 LLM 生成流程后自动附带
- 菜单 B（仅行情报告）**不会**生成该页签
- 即使 LLM 所有模块均失败/禁用，只要按过菜单 L 就会创建，但仅显示模块明细表（无汇总数据）

### 结构

页签分两个区域：

#### ① 汇总数据区（顶部，仅在有实际 API 调用时显示）

以键值对形式列出本会话的 LLM 整体用量：

| 字段 | 说明 | 示例 |
|------|------|------|
| API 调用次数 | 本次生成实际发起的 API 请求次数 | `4 次` |
| 模型 | 使用的模型名称 | `deepseek-v4-flash` |
| Endpoint | API 端点地址 | `https://api.anthropic.com/v1/messages` |
| 输入 Token | 所有请求的输入 Token 总和 | `12,345` |
| 输出 Token | 所有请求的输出 Token 总和 | `5,678` |
| 总 Token | 输入+输出合计 | `18,023` |
| 缓存命中 Token | 缓存命中的 Token 数（仅 >0 时显示） | `2,100` |
| 累计费用 | 按模型定价估算的总费用 | `¥0.0254` |

> 无 API 调用时（全部命中 LLM 缓存/全部失败/全部禁用），该区域隐藏。

#### ② 模块明细表

每行对应 4 个 LLM 子模块之一，包含以下列：

| 列 | 说明 | 示例值 |
|----|------|--------|
| 模块 | LLM 子模块中文名称 | `全球政经局势` |
| 状态 | 该模块的执行结果 | `成功` / `缓存` / `已禁用` / `LLM API 调用失败` |
| 模型 | 该模块实际使用的模型 | `deepseek-v4-flash` |
| 总 Token 用量 | 该模块的输入+输出 Token 合计 | `4,521` |
| 输入 Token | 该模块的输入 Token 数 | `3,200` |
| 输出 Token | 该模块的输出 Token 数 | `1,321` |
| 缓存命中 Token | 该模块的缓存命中 Token 数（仅 >0 时显示数字） | `2,100` |
| 费用 | 该模块的估算费用 | `¥0.0063` |
| LLM 缓存 | 是否命中 LLM 缓存 | `✓` / `—` |
| Thinking | 是否启用了 Extended Thinking | `✓` / `—` |

##### 状态颜色标识

| 状态 | 标色 | 含义 |
|------|------|------|
| **成功** | 绿色 | API 调用成功，生成正常 |
| **缓存** | 蓝色 | 结果来自 LLM 缓存，未发起 API 请求 |
| **已禁用** | 灰色 | 该模块在配置中未启用 |
| 失败（LLM 未配置 / API 调用失败 / 网络连接失败 / 请求超时 / 熔断冷却中） | 红色 | 该模块执行出错，展开查看具体原因 |

##### 状态说明

- **LLM 未配置**：`llm_key.json` 或 `llm_settings.json` 未正确设置 API Key
- **API 调用失败**：LLM 服务端返回了错误（如 400/500）
- **网络连接失败**：客户端无法连接到 LLM 端点（如 DNS 解析失败、连接被拒）
- **请求超时**：LLM API 响应时间超过设定的超时阈值
- **熔断冷却中**：该端点因连续错误被熔断器临时禁止访问，等待恢复

## HTML 报告

单页渲染以上全部 12 个功能页签（含 LLM API 用量），CSS 样式桌面端优先。额外特性：
- 盈亏正数红色、负数绿色着色
- 取价方式蓝色标识（与 Excel 端规则一致）
- 新闻来源可点击跳转
- 基金业绩评价带颜色标签
- LLM API 用量章节展示各模块 Token 消耗、费用估算及 per-module 模型/用量明细
- 页脚标注生成时间和版本号
- LLM 内容为条件渲染（仅菜单 L 时显示）

# 基金业绩评价标准

基金业绩分析采用 **三层计算逻辑**，数据来源于天天基金 API：

## 第 1 层：基础评级

基于同类排名百分位（`Data_rateInSimilarPersent`）：

| 排名百分位 | 基础标签 |
|:-----------|:---------|
| ≤ 20%（前 1/5） | **优秀** |
| 20% ~ 30% | **良好** |
| 30% ~ 50% | **稳定** |
| > 50%（后 1/2） | **偏差** |

> API 无百分位数据时降级使用排名/总数折算百分位。

## 第 2 层：超额收益修正

基于 `Data_performanceEvaluation` 中的超额收益评分调整评级：

| 超额收益评分 | 修正规则 |
|:-------------|:---------|
| ≥ 80 | 基础评级**上调一级**（如 良好 → 优秀） |
| 40 ~ 80 | 维持基础评级不变 |
| < 40 | 基础评级**下调一级**（如 稳定 → 偏差） |

## 第 3 层：显示与标色

| 最终标签 | Excel / HTML 标色 | 显示文本 |
|:---------|:------------------|:---------|
| **优秀** | 红色 `#CC0000` | 持续跑赢基准，超额收益显著 |
| **良好** | 默认 | 稳定跑赢基准，组合管理得当 |
| **稳定** | 蓝色 `#0066CC` | 收益率稳健，波动控制良好 |
| **偏差** | 绿色 `#009900` | 近期表现欠佳，需关注持仓变化 |
