## 前置准备

| # | 操作 | 说明 |
|:-:|:-----|:-----|
| 0.1 | 启动 Web 模式 | `.venv/bin/python -m src.python.web`（或 `launch.sh web`），默认监听 `http://127.0.0.1:8000` |
| 0.2 | 浏览器打开首页 | Chrome 或 Edge（90+，主验）；Firefox 90+（抽验）。首次应看到 7 个卡片：①上传 ②生成 ③配置编辑 ④进度 ⑤结果 ⑥运行状态 ⑦日志 |
