# 端到端性能测试报告

## 概述

- **测试时间**: 2026-07-20
- **持仓规模**: Phase1/2: 20 品种（含股票+基金），Phase3: 50 品种
- **测试模式**: basic（仅 Excel）/ both（Excel+HTML）
- **性能目标**: basic 模式 ≤ 60s

## 各阶段耗时

| 阶段 | 耗时 | 判定 | 说明 |
|:-----|-----:|:----|:-----|
| 数据准备（持仓+详情模拟） | 0.00s | — | 合成 20 品种持仓与详情数据 |
| Phase 1: basic Excel | 29.69s | ✅ 达标（≤60s） | 仅 Excel 生成，不含数据获取/LLM |
| Phase 2: both HTML+Excel | 213.30s | — | HTML + Excel 双输出，不含 LLM |
| Phase 3: 50品种压力测试 | 2.29s | — | 大持仓场景下的 Excel 生成 |
| **合计** | **245.28s** | — | 三个阶段串联总耗时 |

## 性能基准结论

### basic 模式（Phase 1）
**✅ 达标（≤60s）**。
20 品种 basic 报告生成耗时 **29.69s**，达到性能目标 60s。

### both 模式（Phase 2）
HTML + Excel 双输出耗时 **213.30s**。
不含 LLM 分析生成。

### 大持仓压力测试（Phase 3）
50 品种 basic Excel 生成耗时 **2.29s**。

## 环境

- **平台**: win32
- **Python**: 3.13.0

## 备注

- 所有外部数据源（指数、基金排行、行业分类、概念数据）均已 mock，
  测试结果仅反映本地计算管线性能
- LLM 生成环节已 mock 跳过，实际 full 模式会额外增加 LLM 调用耗时
- 实际耗时受硬件配置、磁盘速度、缓存状态等因素影响
